Enabling keyed sources

Set the environment variable and restart the service. Keys are never sent to the browser or logged. 

# /etc/threattrove/threattrove.env
ABUSECH_AUTH_KEY=...      # auth.abuse.ch — MalwareBazaar, ThreatFox, URLhaus
VT_API_KEY=...            # virustotal.com — files, URLs, domains, IPs
OTX_API_KEY=...           # otx.alienvault.com (optional, raises limits)
URLSCAN_API_KEY=...       # urlscan.io (optional, raises limits)
HA_API_KEY=...            # hybrid-analysis.com
MALSHARE_API_KEY=...      # malshare.com
TRIAGE_API_KEY=...        # tria.ge
GSB_API_KEY=...           # Google Safe Browsing v4
PHISHTANK_APPKEY=...      # phishtank.com

The free sources (CIRCL hashlookup, AlienVault OTX, urlscan.io search, DNS, RDAP and Certificate Transparency) answer without any key, so a fresh install is useful immediately. Reverse IP lookups are free but rate limited, so they stay off until you set TT_ENABLE_REVERSE_IP=1.

Shared daily allowance

The three VirusTotal sources spend one key's allowance between them: a lookup of a hash, a URL and a domain is three requests. The app keeps a per-day counter and stops asking once the budget is gone, so a busy day ends with “budget spent” answers instead of rate-limit errors. Raise or lower it with TT_VT_DAILY_BUDGET (default 400; the free key allows 500).

VirusTotal's domain and IP lookup is off by default (TT_VT_DOMAINS=1 turns it on). A stray engine flag on a shared IP address or a popular domain says almost nothing, so this endpoint mostly buys noise, and the allowance is better spent on files and URLs.
