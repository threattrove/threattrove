API

JSON over HTTP, no authentication on a private deployment. Put it behind a reverse proxy — or an API gateway — if you expose it to the internet. Rate limit: {{ rate_limit }} requests per minute per IP.

Endpoints

MethodPathReturns
GET/api/v1/hash/<md5|sha1|sha256>verdict for a file hash
GET/api/v1/url?url=<url>verdict for a URL
GET/api/v1/domain?domain=<name>verdict for a domain
GET/api/v1/ip?ip=<addr>verdict for an IP address
GET/api/v1/lookup?q=<anything>auto-detects the indicator type
POST/api/v1/bulkqueue a bulk job, returns 202 + job id
GET/api/v1/bulk/<id>job status and verdict counts
GET/api/v1/bulk/<id>/itemsper-indicator results
GET/api/v1/sourcesconfigured sources and their state
GET/api/v1/statsinstance statistics
Append &fresh=1 to bypass the result cache.

Examples

# single hash
curl -s '{{ request.url_root }}api/v1/hash/44d88612fea8a8f36de82e1278abb02f' | jq .verdict

# URL
curl -s '{{ request.url_root }}api/v1/url?url=https%3A%2F%2Fexample.com%2Flogin' | jq '.verdict, .headline'

# bulk CSV
curl -s -F 'file=@feed.csv' -F 'label=weekly' {{ request.url_root }}api/v1/bulk

# poll
curl -s '{{ request.url_root }}api/v1/bulk/<job_id>' | jq .status
